Research Project · Braiding

BarCord

A braided code that embeds information directly in a cord by changing its repeating color pattern and structural segment length, without adding electronics or special materials.

  • Braiding
  • Physical Encoding
  • Color Pattern
  • Textile

Physical Representation

Adding a two-strand twist at selected positions changes two visible properties of the cord.

  • Color pattern: The strand arrangement and repeating pattern represent the two bit states.
  • Segment length: Short and long structural segments represent zeros and ones.

Encoding

  1. Convert the source information into a binary sequence.
  2. Braid the selected base cord structure.
  3. Insert two-strand twists at chosen positions.
  4. Form the bit sequence through changes in color pattern or structural segment length.

Decoding

In the current prototype, the repeating color pattern or structural segment length is inspected visually and each region is manually interpreted as a zero or one.

Project Details

Structure
Braided cord with inserted two-strand twists
Representations
Color pattern and segment length
Density
1.36 bits/cm (32-bit color-pattern sample)
Main Challenge
Accumulated twisting can flip the visible bit pattern.
