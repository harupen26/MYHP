Research Project · Embroidery

Stitch Barcode

A method that resamples any single-line SVG with different stitch lengths, embedding binary data and path information directly into an embroidered line.

  • Embroidery
  • Computer Vision
  • SVG
  • K-means

Physical Representation

SymbolStitch lengthRole
01.2 mmBinary data
12.4 mmBinary data
M4.5–7.2 mmMarker

The 0-M-1 start marker establishes the reading direction, while cross-skip patterns define the intended route through path crossings.

Encoding

  1. Convert the source information into a binary sequence.
  2. Resample a single-line SVG using the stitch length assigned to each bit.
  3. Insert a start marker and cross-skip patterns at path crossings.
  4. Fabricate the encoded path with a Singer Quantum Futura CE-200 embroidery machine.

Decoding

  1. Segment the embroidery image in HSV color space.
  2. Measure each stitch and use K-means with thresholding to classify zeros, ones, and markers.
  3. Reconstruct the reading order using endpoint connections, the start marker, and cross-skip patterns.
  4. Convert the ordered stitch sequence back into binary data.

Project Details

Machine
Singer Quantum Futura CE-200
Methods
HSV segmentation, geometry analysis, K-means
Density
4.64 bits/cm (32-bit sample)
Main Challenge
Thread tension changes stitch geometry.
