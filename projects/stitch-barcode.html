Stitch Barcode

A method that resamples a single-line vector path with different stitch lengths, embedding binary data and path information directly into an embroidered line.

  • Embroidery
  • Python
  • Image Processing
  • Error-Detection Coding
  • K-means

Physical Representation

SymbolStitch lengthRole
01.2 mmBinary data
12.4 mmBinary data
M4.5–7.2 mmMarker

Start Marker

The 0-M-1 pattern identifies the start point and determines the decoding direction from 0 toward 1.

Skip Markers

Skip markers establish the reading order in advance where nearest-point matching would otherwise become ambiguous.

  • Cross skip: A crossing is encoded as 0-M-M-0 or 1-M-M-1. Connecting the same bit state across the crossing supports intersecting paths with low encoding overhead.
  • Corner skip: A skip marker is inserted at corners below 30° to keep nearest-point matching from jumping to the wrong stitch and to reduce decoding errors.

Encoding

  1. Convert the source information into a binary sequence.
  2. Append a parity bit so that the total number of 0s is even, enabling parity-based error detection during decoding.
  3. Insert a start marker and skip markers (cross-skip and corner-skip patterns).
  4. Resample the single-line vector path using the stitch length assigned to each symbol.
  5. Fabricate the encoded path with a Singer Quantum Futura CE-200 embroidery machine.

Decoding

  1. Segment the embroidery image in HSV color space.
  2. Measure each stitch and use K-means with thresholding to classify 0, 1, and M.
  3. Locate M segments to identify the start marker as the start point and direction, and identify skip markers as controlled skip points.
  4. Reconstruct the reading order using endpoint connections, the start marker, and skip patterns.
  5. Convert the ordered stitch sequence back into binary data and use the even-zero parity check to detect errors.
