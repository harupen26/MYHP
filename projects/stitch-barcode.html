Research Project · Embroidery

Stitch Barcode

任意の一本線SVGを異なる長さのステッチで再サンプリングし、刺繍された線の中にバイナリ情報と経路情報を埋め込む手法です。

  • Embroidery
  • Computer Vision
  • SVG
  • K-means

Physical Representation

SymbolStitch lengthRole
01.2 mmBinary data
12.4 mmBinary data
M4.5–7.2 mmMarker

開始マーカー 0-M-1 が読み取り方向を示し、交差部ではcross-skipパターンが経路を定義します。

Encoding

  1. 情報をバイナリ列に変換する。
  2. 一本線SVGをビットに対応するステッチ長で再サンプリングする。
  3. 開始マーカーと交差部のcross-skipを挿入する。
  4. Singer Quantum Futura CE-200で刺繍する。

Decoding

  1. 刺繍画像をHSV色空間でセグメンテーションする。
  2. 各ステッチの長さを測定し、K-meansと閾値処理で0・1・マーカーを分類する。
  3. 端点間の接続、開始マーカー、cross-skipを使って読み取り順を復元する。
  4. ステッチ列をバイナリデータへ戻す。

Project Details

Machine
Singer Quantum Futura CE-200
Methods
HSV segmentation, geometry analysis, K-means
Density
4.64 bits/cm (32-bit sample)
Main Challenge
Thread tension changes stitch geometry.
