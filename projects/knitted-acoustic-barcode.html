Research Project · Machine Knitting

Knitted Acoustic Barcode

ガーター編みの凹凸間隔にバイナリデータを埋め込み、布をなぞったときの音響波形から情報を復号するバーコードです。

  • Machine Knitting
  • Acoustic Sensing
  • Signal Processing
  • K-means

Physical Representation

隆起部分の間隔を変えることで0と1を表します。前床2列を固定し、後床領域の列数を変化させます。

BitStructureInterval
02 front-bed + 2 back-bed rowsShort
12 front-bed + 3 back-bed rowsLong

Encoding

  1. データをバイナリ列に変換する。
  2. 各ビットを短い／長いガーター間隔へ変換する。
  3. カスタムスクリプトでパターン画像を生成する。
  4. image-kp.jsで編み機用命令へ変換し、工業用編み機で出力する。

Decoding

  1. コンタクトマイクを付けたプローブで布をなぞり、USBオーディオインターフェースで録音する。
  2. 50–500 Hzのバンドパス処理と絶対値化を行う。
  3. ピークとピーク間隔を検出する。
  4. K-meansで短い／長い間隔を分類し、0と1へ戻す。

Project Details

Machine
Shima Seiki SWG091N2, 15 gauge
Material
Tamm Petit acrylic yarn
Density
2.42 bits/cm (32-bit sample)
Main Challenge
Sliding-speed variation changes peak intervals.
