Research Project · Acoustic Sensing

Fabric Classification

布から得られる音響信号を解析し、波形と周波数領域の特徴量から素材の違いを識別するプロトタイプです。

  • Machine Learning
  • Acoustic Sensing
  • Signal Processing
  • Textile

Overview

圧電センサーで布の音響応答を取得し、LM358を使った回路で信号を調整してPCへ送ります。Line Length法でスクラッチ区間を検出し、取得した波形とPSDの特徴量から5種類の布を分類します。

Classification Target

このプロジェクトでは0と1を埋め込むのではなく、既存の布が持つ音響的な違いをクラスとして扱います。

Classification Pipeline

  1. 布から音響応答を発生させ、圧電センサーで検出する。
  2. LM358と100 kΩ可変抵抗を用いた回路で信号とゲインを調整する。
  3. USB経由で波形をコンピュータへ取り込む。
  4. Line Length法でイベントを検出し、波形・PSD特徴量を抽出する。
  5. 300サンプルで分類器を学習し、100サンプルで評価する。

Project Details

Methods
Line Length detection, waveform and PSD features, classification
Hardware
Piezo contact microphone, LM358 circuit, USB audio interface
Result
67% overall accuracy across five fabric classes
Skills
Acoustic sensing, circuit design, machine learning
