Research Project · Acoustic Sensing

Fabric Classification

A prototype that analyzes acoustic signals from fabric and identifies material differences using waveform- and frequency-domain features.

  • Machine Learning
  • Python
  • Acoustic Sensing
  • Signal Processing
  • Textile

Overview

A piezoelectric sensor captures each fabric's acoustic response. An LM358-based circuit conditions the signal before it is sent to a computer. Scratch events are detected with the Line Length method, and five fabric types are classified using waveform and power spectral density features.

Classification Target

Rather than embedding 0 and 1, this project treats the naturally occurring acoustic differences between existing fabrics as classification targets.

Classification Pipeline

  1. Generate an acoustic response by swiping the fabric and detect it with a piezoelectric sensor.
  2. Condition the signal and adjust its gain with an LM358 circuit and a 100 kΩ potentiometer.
  3. Transfer the waveform to a computer through a USB audio interface.
  4. Detect scratch events with the Line Length method and extract waveform and PSD features.
  5. Train the classifier on 300 samples and evaluate it on 100 test samples.

Project Details

Methods
Line Length detection, waveform and PSD features, classification
Hardware
Piezo contact microphone, LM358 circuit, USB audio interface
Result
67% overall accuracy across five fabric classes
Skills
Python, acoustic sensing, circuit design, machine learning
